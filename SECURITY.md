# Security policy

Security fixes are supported for the latest published version of
`@suwatte/toolchain`.

Report a suspected vulnerability privately to
[help@mantton.com](mailto:help@mantton.com). Include the affected version, a
clear reproduction, and the expected impact when possible. Please do not open a
public issue for an undisclosed vulnerability.

You should receive an acknowledgement within seven days. Details will remain
private until a fix or coordinated disclosure plan is available.
